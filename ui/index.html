Console administrator

                        

                            The local administrator password gates this console and is verified
                            entirely on this device. It can be changed or wiped only from an
                            active session — there is no remote or offline reset path.
                        

                        

                            

                                
                                Wiping the password erases the local credential file. The next
                                launch of this application returns to the first-boot setup
                                screen, where a new password must be created.
